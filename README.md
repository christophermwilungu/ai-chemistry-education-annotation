AI Chemistry & Education Annotation Portfolio

About This Project

This is a practical AI training and data annotation portfolio project combining chemistry knowledge, education experience, and artificial intelligence.

The project demonstrates skills in data annotation, AI response evaluation, text classification, quality control, and dataset creation.

Project Goals

- Create high-quality datasets for AI training.
- Classify and annotate chemistry and education questions.
- Evaluate AI-generated responses for accuracy, relevance, and clarity.
- Demonstrate consistent annotation and quality-control practices.
- Build practical experience relevant to AI training and data annotation roles.

- General Chemistry

Education

- Question classification

Portfolio Project Structure

The project will include:

1. Chemistry question annotation
2. Education question annotation
3. AI response evaluation
4. Audio annotation examples
5. Image and video annotation examples
6. Quality-control report
7. Final project documentation
